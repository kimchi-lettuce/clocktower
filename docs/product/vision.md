# Product vision

ChristOnline is an all-in-one church management system, built with Daniel Chin. It carries forward what two earlier products each proved, into one coherent platform:

- **CrossCheck** — a community knowledge hub: resource recommendations, trust-weighted voting, and personal notes with hybrid search.
- **Church Welcoming / Attendance App** — live Sunday check-in, welcoming flows, role-scoped access, and warden-approved privacy governance.

ChristOnline replaces separate tools with one system of record for church life. The original project note with setup instructions and history lives here: [[ChristOnline]].

## Who it serves

Church members, visitors, and the people who serve and govern the church (for example wardens). Roles and access tiers are confirmed as features are briefed; the first pass lives in [data governance](../technical/data-governance.md).
