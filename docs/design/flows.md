# Flows

How a person moves through ChristOnline, written stepwise so a non-technical reader can follow. This page collects flows as they are identified; each flow gets a heading of its own.

Flows known so far, carried from the earlier products:

- Sunday check-in and welcoming
- Warden oversight and role-scoped access

When a flow branches — by role, permission, first time versus regular attendance — prefer a canvas over paragraphs. Branches read faster as shapes with labels than as nested bullet lists. Link the canvas from here with one line saying what it shows.
