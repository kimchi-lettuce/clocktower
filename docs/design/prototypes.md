# Prototypes

Prototypes answer questions cheaply, in throwaway code. An entry survives even after the code is deleted, because the outcome is the part worth keeping.

## Entry format

- **Prototype:** what was built and where it lives (app, script, mockup page)
- **Question:** what it was meant to test
- **Outcome:** what was learned and what changed because of it

When working through several prototype options, put them side by side on a canvas so the differences are visible at a glance, then write the single chosen outcome here.
