What Git is

Git is a time machine for the project. It keeps a history of saved changes, lets us see who changed what, and lets everyone work from the same shared copy on GitHub.

Getting started

  1. Create a GitHub account at github.com/signup.
  2. If Git isn’t installed yet, run the first command below.
  3. Copy and paste the commands into Terminal.
  4. If Git asks for sign-in, follow the prompts.
xcode-select --install
git --version
git clone https://github.com/kimchi-lettuce/christ-online.git
cd christ-online

If macOS asks for developer tools, accept the install prompt. When the commands finish, you’ll have the project on your Mac.

Daily workflow

1. Get the latest changes
git pull
2. Save your work
git add .
git commit -m "Short description of what you changed"
3. Share your work
git push
4. Check what changed
git status
This shows what you have changed before you commit.

We’ll keep it simple: pull → edit → commit → push.

If something looks confusing or you get an error, stop and ask. You don’t need to force push or delete anything.
